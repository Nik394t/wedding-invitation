# Свадебное приглашение — главная страница

Scope: единственная страница-открытка, mobile-first. Mode: Experience.
Audience: близкие, открывают ссылку из мессенджера на телефоне. Job: пережить раскрытие письма и без ошибок узнать два дня, время, адреса, дресс-код.
Pinned by user: референс-рилс webgency_invitations (конверт с печатью → арка с цветами → стирание даты → арочный лист → линия двух событий → место с фото), ТЗ `CLAUDE-ПЕРЕДЕЛКА-ПРИГЛАШЕНИЯ.md`. Запрещено: имена, RSVP, таймер, музыка, подарки, «Тили-тили тесто», новые факты.

## Direction contract

THESIS: приглашение — это тиснёный конверт из семейной шкатулки, который вскрывают по сургучной печати; внутри нет ни одной «карточки», только арочные бумажные окна, медальоны и нить. Отказ от свадебного лендинга из прямоугольных блоков.

OWN-WORLD: пудрово-розовая бумага со слепым тиснением роз; бордовый сургуч и бордовая типографская краска; кремовая состаренная бумага; холодная серебряная фольга (линии, медальоны, стираемый слой); килевидная арка (кокошник) как единственная рамка; бумажные розы пыльной палитры. Шрифты: Great Vibes (каллиграфия) и Old Standard TT (антиква русской печати рубежа веков).

STORY: вскрыть печать → увидеть себя-детей в арке → стереть серебро и узнать время двух дней → глава 23 (утренний лист отрывного календаря, ЗАГС) → глава 24 (вечерняя арка с церковью) → образцы тканей дресс-кода → записка внутри письма.

FIRST VIEWPORT: конверт во весь экран: четыре тиснёные створки сходятся в центре под бордовой печатью с сердцем (она же кнопка «Открыть приглашение»); сверху тиснёный заголовок, внизу даты 23 · 24 октября 2026.

FORM: brief-pinned (референс пользователя), вне списка кандидатов; seed не разыгрывался — направление закреплено пользователем. Signature interaction: вскрытие печати (единая последовательность ≈1.3 с) и стирание серебра с медальонов. Motion grammar: бумага раскрывается (clip/створки), фото проявляется (сепия → цвет), нить тянется по скроллу, каллиграфия «пишется» слева направо.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
